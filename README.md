# 顔かくし

SNS に載せる写真の顔を隠し、位置情報などを消す PWA。スマホ・PC 共通。ビルド不要（そのまま置けば動く）。

- 写真は端末の中だけで処理し、外に送らない（CSP で自分自身以外と通信できない）
- 顔を自動で探して隠す。自信の低いものは点線の候補として出し、触ると隠す。横向き・逆さの顔はボタンで探す
- 隠し方：モザイク／ぼかし／スタンプ（絵文字・自分の画像）／塗りつぶし。全部まとめて、または1か所ずつ変えられる
- 顔以外は「囲んで隠す」「なぞって隠す」
- 切り抜き：1:1、4:5、3:4、9:16、1.91:1、16:9、自由。切らずに余白をつけることもできる
- 保存は JPEG。Exif（位置情報・日時・機種）・コメントなどを取り除き、ファイル名も `photo-01.jpg` にする
- 何枚でもまとめて開ける。HEIC は iPhone では開けるが、PC では JPEG にしてから
- 長い辺が 4096px を超える写真は 4096px に縮めて扱う（iPhone の canvas の上限のため）

ぼかしは、モザイクと同じマス目の平均をなめらかにつないだもの（残る情報はモザイクと同じ）。

## ファイル

| ファイル | 役目 |
|---|---|
| `js/app.js` | 画面と操作 |
| `js/detect-worker.js` | 顔を探す（Web Worker） |
| `js/render.js` | 隠す処理・保存する画像 |
| `js/jpeg.js` | Exif を調べる・取り除く |
| `sw.js` | オフライン用の保存、Android の共有受け取り |
| `devtools/` | アイコン作り、確認用（`test.js`、`samples/` は git に入れない） |
| `vendor/` | onnxruntime-web 1.20.1（Microsoft、MIT）、YuNet 2023mar（opencv_zoo、MIT） |

## 手元で動かす

```bash
python -m http.server 8793
```

公開先：https://islandkei28.github.io/kao-kakushi/ （GitHub Pages、main の最上位。push すると反映される）

スマホのホーム画面に追加・オフライン・共有には HTTPS が要る。中身を変えたら `sw.js` の `APP` の版を上げる。
